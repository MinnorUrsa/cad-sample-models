# 小火箭 · CATIA V5 建模步骤

这份文档配合三个东西用：

- `rocket.step` —— 成品（哑实体，打开就能看/打印）
- `rocket_stages/` —— 8 个中间状态，一步一步长成成品
- `make_rocket.vbs` —— 自动建模宏，跑完能拿到带特征树的 CATPart

---

| 项 | 值 |

## 1. 建模顺序

八个特征，顺序就是依赖关系：

```
箭体 → 挖内腔 → 开喷口 → 加头锥 → 切分界槽 → 加加强环 → 做舷窗 → 加尾翼
```

每次做完先 `Update`（工具栏那个红绿灯），确认形状对了再往下。

---

## 2. 逐步操作（Part Design 里全部完成）

### 步骤 1 · 箭体

1. 新建 Part
2. 选 **XY 平面** → 草图
3. 画圆，圆心在原点，**Ø21**
4. 退出草图 → **凸台**，长度 **40**，方向 +Z

### 步骤 2 · 挖内腔

1. 选 **顶面**（z=40 那个面）→ 草图
2. 画同心圆 **Ø17.8**（= 21 − 2×1.6）
3. 退出 → **凹槽**，深度 **37**（留 3 mm 底）

> 用顶面当草图平面，凹槽就会自然朝里切。如果用了 XY 平面，记得把方向翻过来。

### 步骤 3 · 开喷口（锥形）

CATIA 的凹槽只能切直孔，锥形口用「直孔 + 倒角」两步凑出来：

1. 选 **底面**（z=0）→ 草图 → 圆 **Ø11.2** → 凹槽深度 **3**
2. 同一底面 → 草图 → 圆 **Ø5.2** → 凹槽，选 **直到最后**（打通到内腔）
3. 选 Ø5.2 孔的**口部圆边** → **倒角**，长度 **3 mm**，角度 **45°**

这样得到的漏斗和程序里的锥形喷口（Ø11.2 → Ø5.2，深 6）几乎一样。

### 步骤 4 · 加头锥

1. 选 **ZX 平面** → 草图
2. 画一个三角形，三个点：
   - `(0, 40)`
   - `(10.5, 40)`
   - `(0, 57)`
3. 退出 → **旋转体**，角度 **360°**，旋转轴选 **Z 轴**

> 草图里如果提示"没有轴线"，先在草图里画一条从 `(0,0)` 到 `(0,60)` 的直线，右键设为**轴线**，再退出。

### 步骤 5 · 切分界槽

1. 选 **ZX 平面** → 草图
2. 画矩形，四点：
   - `(9.95, 39.5)`
   - `(10.7, 39.5)`
   - `(10.7, 40.5)`
   - `(9.95, 40.5)`
3. 退出 → **旋转槽**（Groove），360°，轴选 Z

得到一圈深 0.75、高 1.0 的环形凹槽，箭头和箭身就有了分界。

### 步骤 6 · 加强环

1. 选 **ZX 平面** → 草图
2. 画矩形：
   - `(10.2, 13.6)`
   - `(11.25, 13.6)`
   - `(11.25, 15.2)`
   - `(10.2, 15.2)`
3. 退出 → **旋转体**，360°，轴选 Z

凸出 0.75 的一圈箍，既是装饰也挡得住箭身中段的接缝。

### 步骤 7 · 舷窗

1. 选 **ZX 平面** → 草图
2. 画圆，圆心 `(0, 24.8)`，**Ø8.6**
3. 退出 → **凸台**，长度 **0.9**，方向朝 **−Y**（PlaneZX 的法向就是 −Y，一般不用改）
4. 同一个草图平面再画一个圆，圆心同上，**Ø7.0** → **凹槽**，深度 **1.1**（朝 −Y 切进去）

结果是一个凸起 0.9 的圆框，中间凹进去 0.7 的窗。

### 步骤 8 · 尾翼

1. 选 **ZX 平面** → 草图
2. 画闭合四边形：
   - `(9.5, 0)`
   - `(19.5, 0)`
   - `(12.0, 16)`
   - `(9.5, 13.1)`
3. 退出 → **凸台**，长度 **2**，勾上 **镜像范围**（两侧对称，共 4 mm 厚）
4. 选中这个凸台 → **环形阵列**，参考方向 **Z 轴**，实例 **3**，总角度 **360°**

## 3. 关于 STEP 和草图

**STEP 里没有草图。** AP203/AP214 只存最终 B-rep 曲面，没有约束、没有特征历史、没有草图平面。CATIA 打开就是一块哑实体（dumb solid），能测量、能改模、能布尔，但看不到任何"怎么画出来的"。

想看到过程，只有三条路：

| 方式 | 能给你什么 | 限制 |
|---|---|---|
| `rocket_stages/` 里的 8 个 STEP | 每个阶段的实体形状，按顺序打开就是"生长过程" | 仍是哑实体，8 个独立文件 |
| `make_rocket.vbs` 宏 | 真正的 CATPart，有特征树、有草图、能改尺寸 | 需要 CATIA 在位，本机未实测 |
| 照这份文档手动建 | 100% 可控的特征树 | 花 20~30 分钟 |

宏的用法见脚本开头的注释。它跑完会把没做成的步骤列出来（头锥和尾翼阵列故意留给你手动做，因为这两步用旋转体/环形阵列比写代码更稳）。
