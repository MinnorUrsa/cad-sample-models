# 小火箭 v14 · CATIA V5 手工建模步骤

这份文档配合三个东西用：

- `toys/rocket.step` —— 成品（哑实体，打开就能看 / 打印）
- `toys/rocket_stages/` —— 14 个中间状态，按序号一路长成成品
- `scripts/make_rocket.vbs` —— 自动建模宏，跑完得到带特征树的 CATPart（需 CATIA 在位）

手工走一遍约 30~40 分钟。全部在 **Part Design** 里完成，不需要 GSD。

## 1. 建模顺序

十四步，顺序就是依赖关系：

```
箭体 → 挖腔 → 喷口 → 头锥 → 分界槽 → 加强环 → 裙摆 → 环槽
     → 纵筋 → 检修舱口 → 舷窗 → 姿控口 → 顶针 → 尾翼
```

每做完一步按 **Update**（工具栏红绿灯），确认形状对了再往下。

---

## 2. 逐步操作

### 步骤 1 · 箭体

1. 新建 Part
2. 选 **XY 平面** → 草图 → 画圆 Ø21（圆心在原点）
3. 退出 → **凸台 (Pad)**，长度 **40**，方向 +Z

> 结果：Ø21 × 40 的圆柱。对应 `s1_body.step`。

### 步骤 2 · 挖内腔

1. 选**顶面**（z=40）→ 草图 → 同心圆 **Ø18.2**（= 21 − 2×1.4）
2. 退出 → **凹槽 (Pocket)**，深度 **37**（留 3 mm 实心底）

对应 `s2_cavity.step`。

### 步骤 3 · 锥形喷口

CATIA 的凹槽只能直切，锥形用「两段凹槽 + 倒角」凑：

1. 选**底面**（z=0）→ 草图 → 圆 **Ø11.2** → 凹槽深 **3**
2. 同一底面 → 草图 → 圆 **Ø5.2** → 凹槽，类型选 **直到最后 (Up to last)**，打通到内腔
3. 选 Ø5.2 孔的**口部圆边** → **倒角**，长度 **3 mm**，角度 **45°**

对应 `s3_nozzle.step`。

### 步骤 4 · 头锥 + 球头 + 挖空 + 顶针

**4a 锥体**

1. 选 **ZX 平面** → 草图
2. 画三角形，三点：`(0, 40)`、`(10.5, 40)`、`(0, 56)`
3. 退出 → **旋转体 (Shaft)**，360°，轴选 **Z**

**4b 球头**

1. 选 **ZX 平面** → 草图 → 画半圆，圆心 `(0, 55.5)`，**R2.0**
2. 退出 → 旋转体 360°，轴 Z

**4c 挖空头锥**

1. 选 **ZX 平面** → 草图
2. 画四边形：`(0, 38.5)`、`(9.1, 38.5)`、`(0.5, 54.8)`、`(0, 54.8)`
3. 退出 → **旋转槽 (Groove)**，360°，轴 Z

**4d 顶针**

1. 选 **XY 平面** → 草图 → 圆 **Ø1.1**
2. 退出 → 凸台，长度 **4**，起点 z=**55**
3. 选 **ZX 平面** → 草图 → 半圆圆心 `(0, 58)`、**R1.0** → 旋转体 360°

对应 `s4_nose.step`。

### 步骤 5 · 分界槽

1. 选 **ZX 平面** → 草图
2. 画矩形：`(9.9, 39.5)`、`(10.8, 39.5)`、`(10.8, 40.5)`、`(9.9, 40.5)`
3. 退出 → **旋转槽**，360°，轴 Z

对应 `s5_seam.step`。

### 步骤 6 · 加强环

1. 选 **ZX 平面** → 草图
2. 画矩形：`(10.0, 13.6)`、`(11.25, 13.6)`、`(11.25, 15.2)`、`(10.0, 15.2)`
3. 退出 → **旋转体**，360°，轴 Z（凸出 0.75）

对应 `s6_rib.step`。

### 步骤 7 · 裙摆

1. 选 **ZX 平面** → 草图
2. 画闭合轮廓（外扩 + 内壁）：
   - `(10.5, 0)` → `(11.15, 0)` → `(11.15, 1.8)` → `(10.5, 1.8)` → `(9.5, 1.8)` → `(9.5, 0)` → 闭合
3. 退出 → **旋转体**，360°，轴 Z

对应 `s7_skirt.step`。

### 步骤 8 · 两道环槽 + 头锥凹环

**8a 箭体两道环槽**（z=21.6 和 z=31.6，各宽 0.9）

1. 选 **ZX 平面** → 草图 → 矩形 `(9.95, 21.15)`、`(10.8, 21.15)`、`(10.8, 22.05)`、`(9.95, 22.05)`
2. 退出 → **旋转槽**，360°，轴 Z
3. 复制该旋转槽 → **环形阵列** 沿 Z，实例 **2**，总角度 **360°**（得到 z=31.6 那道）

**8b 头锥凹环**（z≈47.2）

1. 选 **ZX 平面** → 草图 → 矩形 `(5.785, 46.8)`、`(7.035, 46.8)`、`(7.035, 47.6)`、`(5.785, 47.6)`
2. 退出 → **旋转槽**，360°，轴 Z

对应 `s8_rings.step`。

### 步骤 9 · 4 条纵向加强筋（分段）

每条筋被环槽天然打断成三段，z 区间：(17.5, 20.6)、(22.6, 30.6)、(32.6, 38.9)。

1. 选 **ZX 平面** → 草图
2. 画圆：圆心 `(10.3, 0)`、**R0.9**
3. 退出 → **凸台**，长度 **3.1**，起点 z=**17.5**
4. 同样方法做中段（z=22.6，长 8.0）和上段（z=32.6，长 6.3）
5. 把三段编成一组 → **环形阵列** 沿 Z，实例 **4**，总角度 **360°**

对应 `s9_ribs.step`。

### 步骤 10 · 检修舱口

1. 选 **ZX 平面** → 草图
2. 画矩形：`(9.3, 22.0)`、`(11.7, 22.0)`、`(11.7, 31.0)`、`(9.3, 31.0)`（宽 2.4、高 9.0）
3. 退出 → **凹槽**，深度 **5.6**，方向 **−Y 和 +Y 双侧**（对称）
   > 槽别开太宽：y=±2.8 处筒面半径约 10.1，槽底 9.5，留 0.6 mm；开到 7.0 只剩 0.4 mm，等于一条线宽，打不出来。
4. 槽内做把手：选 **ZX 平面** → 草图 → 矩形 `(8.9, 25.0)`、`(10.1, 25.0)`、`(10.1, 28.0)`、`(8.9, 28.0)` → 凸台，长度 **3.0**，对称

对应 `s10_hatch.step`。

### 步骤 11 · 双舷窗

**11a 唇环**（±Y 各一个）

1. 选 **ZX 平面** → 草图 → 两个同心圆 **Ø12** 与 **Ø10**，圆心 `(0, 24.8)`
2. 退出 → **凸台**，长度 **1.2**，方向 **−Y**，起点 y=**−9.9**（= −(10.5−0.6)），让环身埋进筒壁 0.6
3. 复制该凸台 → **镜像** 到 +Y 侧。**注意方向会跟着翻**：+Y 侧起点 y=+9.9，长度仍 1.2，朝 +Y 长。如果镜像后凸台浮在筒外，就是这里错了。

**11b 球冠坑**

1. 用 **球体 (Sphere)** 工具，中心 `(0, −17.2, 24.8)`，**R7.6** → 布尔减去
2. 同法在 `(0, +17.2, 24.8)` 再减一个

> 球心离轴心 17.2，球半径 7.6，与 Ø21 圆柱面（R10.5）相交得到 **Ø7.2** 的开口、深 **0.9** 的球冠坑；
> 坑底到内腔壁（R9.1）还剩 **0.5 mm**，所以是盲窗、不会打穿。
> 原来用 R8.4 @ 17.5 时坑底正好落在 R9.1，壁厚归零，切片会直接判成通孔——这就是上一版「窗悬空」的来源之一。

对应 `s11_ports.step`。

### 步骤 12 · 头锥姿控喷口（4 个）

1. 选 **XY 平面** → 草图 → 圆 **Ø2.8**，圆心距轴 **4.87**，方位 **45°**
2. 退出 → **凹槽**，深度 **0.9**，起点 z=**48.4**
3. 选中该凹槽 → **环形阵列** 沿 Z，实例 **4**，总角度 **360°**

对应 `s12_rcs.step`。

### 步骤 13 · 顶针（如步骤 4d 已做可跳过）

对应 `s13_probe.step`。

### 步骤 14 · 尾翼

1. 选 **ZX 平面** → 草图
2. 画闭合五边形（X 为径向、Y 为轴向）：
   - `(9.3, 0)`
   - `(19.5, 0)`
   - `(12.74, 12.5)`
   - `(10.38, 12.5)`
   - `(9.3, 12.5)`
3. 退出 → **凸台**，长度 **2**，勾 **镜像范围**（两侧对称，共 4 mm 厚）
4. 选中该凸台 → **环形阵列** 沿 Z，实例 **3**，总角度 **360°**

对应 `s14_fins.step`。

## 3. 关于 STEP 和草图

**STEP 里没有草图。** AP203/AP214 只存最终 B-rep 曲面，没有约束、没有特征历史、没有草图平面。
CATIA 打开就是一块哑实体（dumb solid），能测量、改模、布尔，但看不到「怎么画出来的」。

想看到过程，只有三条路：

| 方式 | 能给你什么 | 限制 |
|---|---|---|
| `rocket_stages/` 的 14 个 STEP | 每个阶段的实体形状，按序号打开就是生长过程 | 仍是哑实体，14 个独立文件 |
| `make_rocket.vbs` 宏 | 真正的 CATPart，有特征树、有草图、能改尺寸 | 需 CATIA 在位，本机未实测 |
| 照这份文档手动建 | 100% 可控的特征树 | 30~40 分钟 |

## 4. 打印建议

- **头朝上竖着打**：头锥和箭体是旋转体，尾翼在底部贴床，支撑少
- 壁厚 1.4 = 3.5 圈 0.4 挤出，够结实；纵筋再补一层
- 舷窗唇环凸出 0.6，0.2 层高下是 3 层，打得出但边缘略钝
- 球冠坑深 0.9，底面是曲面，不需要支撑
- 导出 STL 后建议过一遍网格修复（删退化面 / 补洞）；OCC 在球头顶点会吐一个零面积三角形，部分切片器会因此报空层
- 想要摆件效果：0.16 层高 + 15% 填充
- 双色打印：箭体一色、头锥 + 尾翼一色，需要拆件版本（可另出）
