# 小火箭 v16 · CATIA V5 手工建模步骤

这份文档配合三个东西用：

- \`toys/rocket.step\` —— 成品（哑实体，打开就能看 / 打印）
- \`toys/rocket_stages/\` —— 12 个中间状态，按序号一路长成成品
- \`scripts/make_rocket.vbs\` —— 自动建模宏，跑完得到带特征树的 CATPart（需 CATIA 在位）

手工走一遍约 30~40 分钟。全部在 **Part Design** 里完成，不需要 GSD。

> **v16 是实心件**：步骤 2（挖内腔）与 4c（挖空头锥）**跳过不建**，其余照旧。
> 实心不是 100% 填充——模型不留内腔，切片时按 15% 填充，17 min；若切片要 100% 则 39.9 min。
> 这一步只影响内部，外观与 v15 逐字节一致（\`rocket_v16_cut.png\` 有剖面对比）。
> 步骤编号沿用 v15（与 \`rocket_stages/\` 的文件名一一对应），跳过的两步保留编号并标注。

> **尺寸口径**：正文所有尺寸都是**缩放前**的建模值（箭体 Ø21 × 40）。
> 生成器最后对整体做 **0.97 等比缩放**，所以 \`rocket_stages/\` 里的 STEP 会比正文数字小 3%。
> 手工建到第 13 步后再用 **缩放 (Scaling)** 工具整体乘 0.97，就和文件完全对上了。

## 1. 建模顺序

十二步，顺序就是依赖关系（v16 跳过「挖腔」）：

\`\`\`
箭体 → 喷口 → 头锥 → 分界槽 → 加强环 → 裙摆 → 环槽
     → 纵筋 → 检修盖板 → 舷窗 → 姿控口 → 尾翼
\`\`\`

每做完一步按 **Update**（工具栏红绿灯），确认形状对了再往下。

---

## 2. 逐步操作

### 步骤 1 · 箭体

1. 新建 Part
2. 选 **XY 平面** → 草图 → 画圆 Ø21（圆心在原点）
3. 退出 → **凸台 (Pad)**，长度 **40**，方向 +Z

> 结果：Ø21 × 40 的圆柱。对应 \`s1_body.step\`。

### 步骤 2 · 挖内腔（v16 跳过）

v15 在这里从顶面挖 Ø18.2 × 37.6 的内腔，留 1.4 mm 侧壁 + 2.4 mm 底板。
**v16 是实心件，这一步不做**，箭体保持 Ø21 × 40 的整根圆柱。

> 为什么改：空壳没有"内部体积"可填，切片填充率对它形同虚设（15%/20%/100% 是同一个时间）。
> 实心后 15% 填充才有意义，耗料 5 396 mm³ ≈ 原空壳 5 371 mm³，时间不变而强度上去。

### 步骤 3 · 锥形喷口

1. 选**底面**（z=0）→ 草图 → 圆 **Ø11.2**
2. 退出 → **凹槽**，深度 **6**，勾选 **拔模** 或改用「多截面」更省事：
   - 更简单的做法：底面画 Ø11.2，再用 **凹槽 + 底部倒角 3×45°** 近似
3. 若用多截面：底面 Ø11.2 → z=6 处 Ø5.2 的 **放样槽**

对应 \`s3_nozzle.step\`。

### 步骤 4 · 头锥 + 球头 + 挖空

**4a 锥体**

1. 选 **ZX 平面** → 草图
2. 画三角形，三点：\`(0, 40)\`、\`(10.5, 40)\`、\`(0, 56)\`
3. 退出 → **旋转体 (Shaft)**，360°，轴选 **Z**

**4b 球头**

1. 选 **ZX 平面** → 草图 → 画半圆，圆心 \`(0, 55.5)\`，**R2.0**
2. 退出 → 旋转体 360°，轴 Z

**4c 挖空头锥（v16 跳过）**

v15 在这里用旋转槽掏空锥体（z=38.5 起，到 z=53 收口到 Ø2.0，避免锥顶壁厚掉到 0.2 mm）。
**v16 实心，这一步不做。**

> 两步必须同时取舍：只删 4c 不删步骤 2，会在锥体里留一根封闭空管，切片器会报内部空腔；
> 所以要么两步都做（v15 空壳），要么都不做（v16 实心）。

对应 \`s4_nose.step\`。

### 步骤 5 · 分界槽

1. 选 **ZX 平面** → 草图
2. 画矩形：\`(10.2, 39.5)\`、\`(10.8, 39.5)\`、\`(10.8, 40.5)\`、\`(10.2, 40.5)\`
3. 退出 → **旋转槽**，360°，轴 Z

> 槽深 0.6。v15 空壳时要保证槽底 r=10.2 与内腔 r=9.1 之间留 1.1 mm 残留壁；
> v16 实心后这道槽只是外观分界线，不再有削壁风险。

对应 \`s5_seam.step\`。

### 步骤 6 · 加强环

1. 选 **ZX 平面** → 草图
2. 画矩形：\`(10.0, 13.6)\`、\`(11.25, 13.6)\`、\`(11.25, 15.2)\`、\`(10.0, 15.2)\`
3. 退出 → **旋转体**，360°，轴 Z（凸出 0.75）

对应 \`s6_rib.step\`。

### 步骤 7 · 裙摆

1. 选 **ZX 平面** → 草图
2. 画闭合轮廓（外扩 + 内壁）：
   - \`(10.5, 0)\` → \`(11.15, 0)\` → \`(11.15, 1.8)\` → \`(10.5, 1.8)\` → \`(9.5, 1.8)\` → \`(9.5, 0)\` → 闭合
3. 退出 → **旋转体**，360°，轴 Z

对应 \`s7_skirt.step\`。

### 步骤 8 · 两道主环槽

z=21.6 和 z=31.6，各宽 0.9、深 0.45。

1. 选 **ZX 平面** → 草图 → 矩形 \`(10.3, 21.15)\`、\`(10.75, 21.15)\`、\`(10.75, 22.05)\`、\`(10.3, 22.05)\`
2. 退出 → **旋转槽**，360°，轴 Z
3. 复制该旋转槽 → **环形阵列** 沿 Z，实例 **2**，总角度 **360°**（得到 z=31.6 那道）

> **头锥不设环槽。** 圆柱切刀在锥面上半段必然穿透——锥面越往上越细，z≈47.8 时锥面半径已小于槽底半径。
> 要做对得沿锥面斜切，视觉收益不值这个风险，v15 直接删掉。

对应 \`s8_rings.step\`。

### 步骤 9 · 4 条纵向加强筋（分段）

每条筋被环槽天然打断成三段，z 区间：(17.5, 20.6)、(22.6, 30.6)、(32.6, 38.9)。

1. 选 **ZX 平面** → 草图
2. 画圆：圆心 \`(10.35, 0)\`、**R1.15**
3. 退出 → **凸台**，长度 **3.1**，起点 z=**17.5**
4. 同样方法做中段（z=22.6，长 8.0）和上段（z=32.6，长 6.3）
5. 三段编成一组 → **环形阵列** 沿 Z，实例 **4**，总角度 **360°**，起始 45°

> 圆心半径 10.35、R1.15 → 外露 1.0 mm。上一版 R0.9 只露 0.6，看着像接缝而不是肋条。

对应 \`s9_ribs.step\`。

### 步骤 10 · 检修盖板（外凸，不切壁）

上一版是**凹槽**，深 5.6 直接把 1.4 mm 筒壁削到 0.4 mm（≈一条线宽），一捏就破。
v15 改成**外凸盖板**：不动筒壁，只在外面贴一块板。

1. 选 **XY 平面** → 草图 → 矩形 1.0 × 5.6（径向 × 周向）
2. 退出 → **凸台**，长度 **9.0**（z 向），起点 z=**22.0**
3. 平移 / 定位到 \`x = 10.4\`（埋入 0.1，外露 0.9）
4. 把手：再画 1.2 × 3.0 的矩形 → 凸台 1.6，定位到 \`x = 10.9\`（外露 1.6）

对应 \`s10_hatch.step\`。

### 步骤 11 · 双舷窗

**11a 唇环**（±Y 各一个）

1. 选 **ZX 平面** → 草图 → 两个同心圆 **Ø12** 与 **Ø9.6**，圆心 \`(0, 24.8)\`
2. 退出 → **凸台**，长度 **1.2**，方向 **−Y**，起点 y=**−9.9**（= −(10.5−0.6)），让环身埋进筒壁 0.6
3. 复制该凸台 → **镜像** 到 +Y 侧。**注意方向会跟着翻**：+Y 侧起点 y=+9.9，长度仍 1.2，朝 +Y 长。如果镜像后凸台浮在筒外，就是这里错了。

**11b 球冠坑**

1. 用 **球体 (Sphere)** 工具，中心 \`(0, −18.8, 24.8)\`，**R9.0** → 布尔减去
2. 同法在 \`(0, +18.8, 24.8)\` 再减一个

> 球心离轴心 18.8，球半径 9.0，最深点 y = 9.8，筒面 10.5 → **坑深 0.7**。
> v15 空壳时坑底到内腔壁只剩 0.70 mm，是"盲窗"的极限；v16 实心后坑底就是实体，
> 0.7 的深度保留原设计，视觉深度靠外凸唇环补。

对应 \`s11_ports.step\`。

### 步骤 12 · 头锥姿控喷口（4 个）

上一版用圆柱凹槽，起点在锥面内侧 0.6 mm、再向内 0.9 mm，**整根埋在壁里，外面根本看不见**。
v15 改成**外切球冠浅坑**，从锥面外侧切进去：

1. 用 **球体** 工具，中心距轴 \`rr + 0.9\`、z = **49.28**，**R1.6** → 布尔减去
   - 其中 \`rr\` 是该高度处的锥面半径：\`rr = 10.5 − 0.58×(10.5−0.8) = 4.87\`
   - 所以球心在半径 5.77
2. 选中该球 → **环形阵列** 沿 Z，实例 **4**，总角度 **360°**，起始 45°

> 开口 Ø2.6、坑深 0.7，残留壁 ≥1.0 mm。

对应 \`s12_rcs.step\`。

### 步骤 13 · 尾翼

1. 选 **ZX 平面** → 草图
2. 画闭合五边形（X 为径向、Y 为轴向）：
   - \`(9.3, 0)\`
   - \`(19.0, 0)\`
   - \`(12.36, 12.5)\`
   - \`(10.32, 12.5)\`
   - \`(9.3, 12.5)\`
3. 退出 → **凸台**，长度 **1.4**，勾 **镜像范围**（两侧对称，共 2.8 mm 厚）
4. 选中该凸台 → **环形阵列** 沿 Z，实例 **3**，总角度 **360°**

对应 \`s13_fins.step\`。

### 收尾 · 整体缩放

1. 选 **插入 > 变换 > 缩放 (Scaling)**
2. 参考选原点，比例 **0.97**

> 生成器就是这么做的：所有特征都用绝对 z 坐标硬编码，改 body_h 会让特征错位，所以用整体缩放。

## 3. 关于 STEP 和草图

**STEP 里没有草图。** AP203/AP214 只存最终 B-rep 曲面，没有约束、没有特征历史、没有草图平面。
CATIA 打开就是一块哑实体（dumb solid），能测量、改模、布尔，但看不到「怎么画出来的」。

想看到过程，只有三条路：

| 方式 | 能给你什么 | 限制 |
|---|---|---|
| \`rocket_stages/\` 的 12 个 STEP | 每个阶段的实体形状，按序号打开就是生长过程 | 仍是哑实体，12 个独立文件 |
| \`make_rocket.vbs\` 宏 | 真正的 CATPart，有特征树、有草图、能改尺寸 | 需 CATIA 在位，本机未实测 |
| 照这份文档手动建 | 100% 可控的特征树 | 30~40 分钟 |

## 4. 打印建议

- **头朝上竖着打**：头锥和箭体是旋转体，尾翼在底部贴床，支撑少
- **填充 15%、外壁 2 圈**：实心几何下这是 17.0 min；加到 3 圈会到 20.8 min，20% 填充是 18.7 min
- 舷窗唇环外凸 0.6，0.2 层高下是 3 层，打得出但边缘略钝
- 球冠坑底面是曲面，不需要支撑
- **导出 STL 后过一遍网格修复**（删退化面 / 补洞 / 统一法向）：OCC 在球头顶点会吐一个零面积三角形，部分切片器会因此报空层
- 想要摆件效果：0.16 层高 + 15% 填充
- 双色打印：箭体一色、头锥 + 尾翼一色，需要拆件版本（可另出）
